# 긴 맵 설계안 (2차)

1차 설계안(434줄)에서 받은 의견을 반영한 두 번째 설계안입니다. 아직 코드에는 넣지 않았습니다.

**받은 의견 → 반영한 것**
- 맵을 더 길게 → 꼭대기 바닥까지 **934줄** (약 42화면, 1차의 2.2배, 지금 테스트 맵의 7배). HUD 높이로 약 933m
- 좌우로만 움직여서 단조로움 → 화면(약 22줄)마다 구조를 바꿈 (굴뚝, 가운데 기둥, 양쪽 지형 사이 통로, 홀, 승강기, 다리 등). 경로 밖 빈 곳은 큰 지형으로 채워서 예시 이미지처럼 동굴·탑 안 같은 모양이 나오게 함
- 구간 끝에 큰 발판 → 각 구간 끝에 **폭의 3/4을 막는 큰 바닥**. 열린 쪽 끝의 위아래 발판을 타고 바닥 위로 올라섬. 올라선 뒤에는 열린 쪽으로 일부러 내려가지 않는 한 아래 구간으로 떨어지지 않음
- 함정이 적음 → 화면마다 함정·적 수를 정해서 구간마다 늘림 (화면당 나무 2 → 벽돌 3 → 얼음 4 → 금 5). 전체 함정·적 수가 1차(약 100개)의 약 1.6배

## 3. 이 설계안을 넣을 때 바뀌는 코드 (아직 안 바꿈)

- `config.py`: `TOWER_PIECES`를 위 29개 목록으로

## 4. 맵을 만든 방식

점프 수치는 1차와 같습니다 (한 번에 최대 2줄 위, 2줄 위면 빈 칸 3칸까지, 같은 높이면 4칸까지, 발판 위 3줄은 머리 공간).

1. **화면마다 구조를 고름**: 아래 종류 중 하나를 골라 그 화면 안에서 경로가 다닐 수 있는 구역을 정함
2. **경로를 쌓음**: 정한 구역 안에서 발판을 놓음 (2줄 위 / 1줄 위 / 같은 높이). 구역 끝에 닿으면 넓은 발판 + 2칸 턱으로 방향을 바꿈
3. **빈 곳을 채움**: 발판 위 머리 공간, 점프가 지나가는 공간, 움직이는 발판 길에서 2칸 넘게 떨어진 빈 곳을 모두 지형(`#`)으로 채움. 지형 아래쪽 모서리는 천장 경사(`]` `[`)로 다듬음
4. **함정·적을 놓음**: 화면마다 정한 수만큼 (아래 5번)

| 화면 종류 | 모양 | 이번 맵에 나온 수 |
|---|---|---|
| 굴뚝 | 한쪽이 큰 지형으로 막혀 좁은 쪽으로만 올라감 | 2 |
| 가운데 기둥 | 가운데 큰 기둥 옆으로 올라가 기둥 위로 넘어감 | 11 |
| 양쪽 지형 사이 통로 | 양쪽 벽이 두꺼워 가운데 길로만 올라감 | 3 |
| 홀 | 넓은 공간에 떠 있는 섬 | 3 |
| 위아래 발판 승강기 | 위아래로 움직이는 발판을 타고 5~8줄 올라감 | 2 |
| 좌우 움직이는 다리 | 같은 높이 먼 발판을 좌우로 움직이는 발판이 이어 줌 | 0 |
| 부서지는 발판 길 | 발판 3개가 연달아 부서지는 발판 | 6 |
| 지그재그 | 특별한 구조 없이 좌우로 (다른 구조가 안 들어갈 때) | 13 |
| 구간 끝 큰 바닥 | 폭 3/4 바닥 + 열린 쪽 승강기 | 3 |

## 5. 구간별 구성

화면당 함정·적 수: **나무 2 (함정 1 + 적 1) → 벽돌 3 (2 + 1) → 얼음 4 (2 + 2) → 금 5 (3 + 2)**. 부서지는 발판 길·움직이는 발판은 이와 별개로 화면 종류에 따라 더 나옴.

| 구간 | 줄 | 발판 폭 | 나오는 함정 | 나오는 적 |
|---|---|---|---|---|
| 나무 | 0~258 | 3~5칸 | 지뢰, 레이저 (주기형) | 고블린, 박쥐 |
| 벽돌 | 259~491 | 2~4칸 | 지뢰, 레이저 (주기형·감지형), 부서지는 발판 | 고블린, 궁수, 가고일, 박쥐 |
| 얼음 | 492~725 | 3~5칸 (미끄러워서 넓게) | 레이저, 지뢰 | 서리 마법사, 가고일, 고블린, 박쥐 |
| 금 | 726~934 | 1~3칸 (1칸은 절반이 반 칸 발판) | 지뢰, 레이저, 부서지는 발판 | 궁수, 가고일, 서리 마법사, 고블린, 박쥐 |

레이저는 두 가지로 놓았습니다.
- **세로**: 점프 빈틈 아래에 위로 쏘는 장치 `U`/`u`, 위에 받는 장치 `*`
- **가로**: 점프 빈틈을 가로질러 한쪽 지형에 박힌 장치 `R`/`L`/`r`/`l`, 반대쪽 지형에 받는 장치 `*`

## 7. 기호표

| 기호 | 뜻 |
|---|---|
| `.` | 빈 칸 |
| `\|` | 탑 안쪽 벽 (실제 파일에서는 바깥에 `.....`가 더 붙음) |
| `#` | 블록·지형 (구간 무늬) / `I` 얼음 블록 (미끄러움) |
| `=` | 얇은 발판 / `~` 얇은 얼음 발판 / `-` 반 칸 발판 |
| `[` `]` | 천장 경사 (지형 아래 모서리) / `\` `/` 바닥 경사 |
| `P` | 시작 위치 |
| `G` 고블린 / `B` 박쥐 (`:` 범위) / `M` 지뢰 | |
| `A` 궁수 / `K` 가고일 / `F` 서리 마법사 | |
| `C` | 부서지는 발판 |
| `H` + `_` | 좌우로 움직이는 발판과 범위 |
| `V` + `_` | 위아래로 움직이는 발판과 범위 (첫 칸 위) |
| `R` `L` `U` `D` / `r` `l` `u` `d` | 레이저 (대문자 주기형 / 소문자 감지형), `*` 받는 장치 |

## 9. 확인한 것 / 확인 못 한 것

**확인함**
- 실제 `Player` 코드로 각 발판의 양 끝과 가운데에서 점프·걸어 떨어지기를 시뮬레이션해서, 시작 위치에서 **꼭대기 바닥(935줄)까지 갈 수 있음**
- 같은 검사로 **떨어져서 갇히는 곳**(갈 수는 있는데 거기서 꼭대기까지 못 가는 곳)도 찾음: **없음** (처음 2군데 나온 곳은 지형으로 메움: 41~43줄 왼쪽, 299~302줄 오른쪽)
- 경로에서 닿지 않는 작은 빈 칸 14곳이 지형 속에 남아 있음 (들어갈 수 없는 곳이라 플레이에는 영향 없음)

**확인 못 함 (직접 플레이해 봐야 함)**
- 적·지뢰·레이저·박쥐는 검사에서 뺌. 화면당 수가 늘어서 가혹한 곳이 있을 수 있음
- 움직이는 발판은 "처음 자리와 범위 양 끝에 있는 발판"으로, 부서지는 발판은 "보통 발판"으로 보고 검사함
- 얼음 위에서 착지 후 미끄러져 떨어지는지
- 맵이 커져서 생길 수 있는 성능 문제
