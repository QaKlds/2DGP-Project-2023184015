테스트 맵 (level_data.py의 ROOM_MAP과 같은 내용)
- 왼쪽 숫자 = 줄 번호 (0 = 맨 아래). 위가 꼭대기
- | 와 | 사이 28칸만 고치면 됨 (칸 번호는 왼쪽 벽 옆이 0, 오른쪽 벽 옆이 27)
- 줄 번호와 | 는 지우지 말고, 한 줄은 항상 28칸

기호
  .  빈 칸              #  블록 (구간 무늬)       I  얼음 블록 (미끄러움)
  =  얇은 발판          ~  얇은 얼음 발판         -  반 칸 발판
  /  바닥 경사 (오른쪽이 높음, 왼쪽으로 미끄러짐)  \  바닥 경사 (왼쪽이 높음, 오른쪽으로 미끄러짐)
  [  천장 경사 (오른쪽 아래가 빔)                 ]  천장 경사 (왼쪽 아래가 빔)
  P  시작 위치          G  고블린                 B  박쥐 (위아래 : 칸까지 날아다님)
  M  지뢰               A  궁수                   K  가고일          F  서리 마법사
  C  부서지는 발판      H / V  좌우 / 위아래 움직이는 발판 (_ 칸까지)
  R L U D / r l u d  레이저 (대문자 주기형, 소문자 감지형), *  받는 장치

구간: 나무 0~58 / 벽돌 59~91 / 얼음 92~125 / 금 126~134 (134줄 = 꼭대기 문 앞 바닥)
